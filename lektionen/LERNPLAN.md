# Python-Lernplan

Ziel: von Null auf Python — praxisnah, mit Übungen und kleinen Helfer-Tools.

## Wie man damit arbeitet

- Jede Lektion: kurzes Beispiel lesen → Übung selbst lösen → mit der Lösung vergleichen.
- Den Code **selbst tippen** (nicht copy-paste) — das ist der halbe Lerneffekt.
- Ausprobieren schlägt Theorie. Fehler sind erwünscht.
- Der Knopf **Erklärung** zeigt Ziel, Erklärung und Beispielcode zur Lektion. **Tipp** gibt Hinweise nacheinander, **Quiz** stellt Verständnisfragen mit Begründung.

## Lektionen

| # | Thema | Inhalt |
|---|-------|--------|
| 01 | Ausgaben & Variablen | `print`, Strings, f-strings |
| 02 | Eingaben & Zahlen | `input`, `int`/`float`, rechnen |
| 03 | Entscheidungen | `if` / `elif` / `else` |
| 04 | Schleifen | `for` & `while` |
| 05 | Listen & Dictionaries | Daten sammeln und ordnen |
| 06 | Funktionen | Code benennen & wiederverwenden |
| 07 | Dateien & Module | Daten speichern, Bibliotheken nutzen |
| 08 | Mini-Projekte | kleine Helfer-Tools bauen |

## Struktur

Jede Lektion hat drei Stufen: Übung, Übung +, Übung ++ — zu jeder Stufe gibt es `beispiel*.py`, `uebung*.py` und `LOESUNG*.py` (Grundstufe ohne Zusatz, dann `-plus`, `-profi`). Erklärungen, Tipps, Quizfragen und die Prüfregeln stehen in `info.json`.

Am bequemsten in PyPad öffnen: Leiste **LERNEN** → Lektion wählen → Beispiel / Übung / Lösung.
Speichern legt die Datei wieder in die Lektion, und Wechseln verliert keine Eingaben.

Zu jeder Stufe gibt es Erklärung, Tipps, Beispiel und Lösung: Stufe im Dropdown wählen, dann **📖 Erklärung** (Ziel, Erklärung, Beispielcode, Tipps) oder **Beispiel** / **Lösung** klicken.
